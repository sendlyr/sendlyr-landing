# Changelog

All notable changes to the Sendlyr landing site are documented here.

## [1.2.0.0] - 2026-10-20

### Added

- A new homepage for the open-source Sendlyr skills: the method, real Typesy lessons, the planted answers every script must find, and three install steps with copyable commands.
- A skills Open Graph image, rendered from `src/og/og-skills.html` with `scripts/render-og.js`.
- A regression test that the first Tab reaches the skip link on every route.

### Changed

- Moved the Signal Validation Pilot page, with its qualification form unchanged, from `/` to `/pilot`.
- Relabelled the pilot hero's indicator examples as observed in historical data rather than validated.
- Corrected the Typesy VIP indicator lift to +11.6pp and +20.1% relative everywhere; the old figures were computed from rounded rates.
- Updated navigation, footer, sitemap, `llms.txt`, the analytics path allowlist and DESIGN.md for the new structure.

### Fixed

- The first Tab no longer skips the skip link on pages with a current navigation item.
- External navigation links no longer send rejected analytics events.

## [1.1.0.0] - 2026-07-21

### Added

- Explore an interactive Revenue Leak Map across activation, conversion, and retention examples.
- Follow the continuous decision layer from behavioral evidence through human approval, delivery, measurement, and the next decision.
- Review a concrete decision package with its state, leading behavior, recommended action, approval boundary, destination, and outcome.
- See familiar data and engagement platforms in the product flow, using local assets and a clear non-endorsement boundary.

### Changed

- Reframed the homepage and public booking actions around finding the customer-journey leak worth fixing first.
- Kept the Typesy result as supporting proof on its approved routes, with the evidence boundary and publication permissions recorded.
- Updated supporting pages, navigation, metadata, Open Graph media, fonts, and public machine-readable summaries to match the wedge-first offer.
- Extended the optional analytics contract for Revenue Leak Map decisions while keeping analytics disabled by default.

### Fixed

- Improved decision-flow feedback-loop positioning, essential text legibility, mobile reflow, and platform-mark sizing.
- Preserved keyboard navigation, visible focus, reduced-motion behavior, no-JavaScript content, hash-aware navigation tracking, and stable responsive layouts.
